# lng-ticket-assistant
Simple Agent for Auto Solving Common Questions

Requires Python 3.13 or newer.

Install from the project root:

```sh
python -m pip install .
```

For development, use an editable install so changes under `src/` take effect immediately:

```sh
python -m pip install -e .
```

Alternatively, use `uv sync` to install the project and its locked dependencies.

Run the installed application:

```sh
lng-ticket-assistant
# Or:
python -m lng_ticket_assistant
```

Python code lives in `src/lng_ticket_assistant/`.
